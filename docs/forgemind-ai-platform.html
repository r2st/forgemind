Overview

Autonomous operations intelligence for manufacturing plants

The platform is designed as a real industrial AI system, not a chatbot shell. It continuously ingests plant telemetry, applies anomaly detection, coordinates autonomous Hermes specialists, executes LangGraph workflows with approval gates, and routes model calls through a configurable OpenAI-compatible API.

Core Architecture

Hermes for agency, LangGraph for control, configurable APIs for inference

Hermes Agent

Autonomous intelligence layer for planning, collaboration, tool execution, operational memory, skill reuse, and persistent learning across Monitoring, RCA, Predictive Maintenance, Optimization, Reporting, ChatOps, and Supervisor agents.

LangGraph

Deterministic workflow engine for stateful execution. It owns investigation, maintenance approval, remediation, and incident escalation graphs, including human approval pauses and resumable operational state.

LLM API Gateway

Configurable OpenAI-compatible boundary for base URL, API key, model selection, request tracing, token accounting, rate limits, and auditability.

Common failure modes

  • Vibration spike on CNC/PRESS: bearing wear, tool imbalance, fixture loosening.
  • Thermal runaway on PRESS/OVEN: cooling-loop fouling, coolant leak, PID drift.
  • Pressure drop on PRESS/CNC: seal failure, leak, pump cavitation.
  • Motor stall on CONVEYOR: jam, overload, VFD fault.

Severity calibration

CRITICAL immediate safety risk, line stop, or scrap over $10k/h.

HIGH production at risk this shift; intervene within 30 minutes.

MEDIUM investigate this shift and monitor closely.

LOW informational or trending condition.

RCA categories

MECHANICAL, ELECTRICAL, THERMAL, HYDRAULIC, PROCESS, OPERATOR, MATERIAL, CONTROL_SYSTEM, UPSTREAM, and EXTERNAL.

RCA outputs must cite machine_id and exact metric evidence, include a confidence score from 0 to 1, and recommend concrete actions with timeframes.

Hermes Agents

Specialists collaborate through shared tools and operational memory

Monitoring Agent

Continuously watches telemetry, identifies anomalies, suppresses low-value noise, and initiates investigations when sustained deviations are detected.

RCA Agent

Retrieves similar past incidents with pgvector, reads telemetry context, correlates events, and produces structured RCA reports with findings and actions.

Predictive Maintenance Agent

Forecasts machine failure risk, estimates maintenance windows, explains degradation drivers, and recommends scheduled interventions.

Production Optimization Agent

Analyzes throughput, defects, downtime, bottlenecks, line balance, and operational efficiency by production line and machine class.

Reporting Agent

Generates shift summaries, executive reports, incident digests, risk narratives, and operational intelligence briefs.

ChatOps Agent

Acts as the operator-facing conversational interface. It answers questions, runs RCA, delegates to the Supervisor, and streams tool activity.

Supervisor Orchestrator

The Supervisor routes user requests and system events to the appropriate specialist. It coordinates multi-agent work, keeps operational context coherent, and uses configurable model endpoints without binding the application to a single provider.

LangGraph Workflows

Deterministic operational workflows around autonomous reasoning

Investigation graph

Fetches incident context, gathers telemetry, invokes RCA, invokes predictive maintenance, assesses severity, gates approval, and notifies downstream systems.

Maintenance approval graph

Builds a maintenance recommendation, checks risk, waits for operator approval for high-impact actions, and emits a trackable workflow run.

Remediation graph

Prepares remediation steps, validates preconditions, requests approval for sensitive actions, and records execution state for auditability.

Incident escalation graph

Escalates critical incidents, fans out notifications, preserves trace IDs, and records operator acknowledgements.

fetch_incident
  -> fetch_telemetry
  -> run_rca
  -> run_pdm
  -> assess_severity
  -> approval_gate
     -> notify
     -> END

If severity is HIGH or CRITICAL, approval_gate pauses the workflow until an operator approves or rejects the action.

Advanced Features

Industrial AI capabilities beyond a basic RAG workflow

Semantic incident search

Vectorized incident memory lets RCA find operationally similar past events, not just keyword matches.

Adaptive alert suppression

Notification rules reduce alert fatigue while preserving high-severity and correlated signals.

Incident replay

Historical anomaly waves can replay through telemetry, detection, workflow, RCA, reporting, and ChatOps.

Confidence scoring

RCA and predictive maintenance outputs quantify uncertainty and expose evidence behind decisions.

Predictive maintenance

Failure risk over 24h and 72h windows drives recommended maintenance timing.

Bottleneck analysis

Production analytics correlates downtime, throughput, defects, and machine health by line.

Semantic caching

A private gateway can lower repeated reasoning cost for similar operational questions.

Agent activity tracing

Agent runs and workflow nodes surface trace IDs, token usage, cost, latency, and model choices.

Deployment

Local development and Kubernetes production paths

Docker Compose

Starts all services, frontend, Postgres with pgvector, Redis, NATS, Prometheus, and Grafana for local development.

cp .env.example .env
docker compose up --build

Kubernetes and Helm

Deploys services, config, ingress, HPA-ready workloads, and optional infrastructure using the Helm chart.

helm upgrade --install forgemind \
  ./infra/helm/factorymind \
  --namespace forgemind

Admin-managed APIs

Configure global and per-agent base URLs, models, API keys, and enabled state from the Admin Panel.

http://localhost:5173/admin
